## CO-RE 启动方式（v0.4.1 起）

```bash
make build                # 生成 vmlinux.h + .bpf.o（首次使用）
./run.sh --guard          # 后台启动检测引擎
./run.sh --ui             # 前台启动面板
```

运行时零编译依赖——`.bpf.o` 预编译 + 内核 BTF 重定位，一次编译处处运行。

## 迁移验证要点（v0.4.1）

- **成功判据**：6 个 E2E 场景在 CO-RE 加载下全过
- **Ring Buffer**：4096B → 1MB（`1<<20`），消除溢出风险（旧容量 ≈ 9 条事件）
- **事件解析**：`struct event` 字段序逐字节保留，handle_event 零改动复用
- **XDP**：bpftool generic 模式 attach（libbpf 1.8 的 bpf_xdp_attach 只支持 native，bridge 网卡需 skb 模式）
